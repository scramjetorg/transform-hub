# Upstream Proposal Template

| Field | Value |
|-------|-------|
| Title | *(one-line summary)* |
| Category | docs / cli / typings / bugfix / feature-request |
| Scope | *(affected packages or subsystems)* |
| Breaking | yes / no |

## Problem Statement

Describe the gap or defect in one to two sentences.

## Current Behavior

What happens today. Include concrete examples, error messages, or code snippets.

## Expected Behavior

What should happen instead.

## Proposed Change

High-level description of the fix or addition. Link to draft code if available.

## Backwards Compatibility

Explain how existing users are affected, or state "No breaking changes."

## Testing Plan

- Unit tests
- Integration tests
- Manual verification steps

## References

- Related issues
- Related PRs
- Documentation links

# @scramjet/manager

The Manager is the orchestration layer that coordinates multiple STH Hubs, providing a single control plane for deploying, monitoring, and managing Sequences across your infrastructure. It collects health and status information from connected Hubs and exposes a unified API.

## When to use

Use `@scramjet/manager` when you operate multiple STH instances and need centralized Sequence management, health monitoring, and API aggregation. Each Hub connects to a Manager; the Manager presents a unified view of all Sequences across all connected Hubs.

For cloud-platform deployments with spaces and multi-tenancy, see [@scramjet/multi-manager](../multi-manager/README.md).

## Quick start

```bash
npm install @scramjet/manager
```

The standalone Manager package currently exposes a programmatic/package entrypoint rather than a fully featured public CLI. Run it from the workspace or from built distribution artifacts in deployments that include this package:

```bash
npm run start -w @scramjet/manager
```

Hubs connect to a Manager using legacy CPM registration fields plus the current verser2 host endpoint and TLS/mTLS configuration:

```bash
scramjet-transform-hub \
  --cpm-id production-node-1 \
  --cpm-url http://manager-host:8200 \
  --verser2-host-url https://manager-host:2443
```

## Stability

This package is **stable**. The Manager API is part of the public runtime contract.

## Configuration

The standalone Manager uses defaults from `@scramjet/manager-config` and Manager types from `@scramjet/types`. File and CLI configuration loading is available through newer `@scramjet/config` command surfaces and the MultiManager package where implemented.

Manager-side verser2 TLS/mTLS settings are documented in the Manager and Hub connection guides. Do not assume Hub-side flags are also Manager-side flags.
